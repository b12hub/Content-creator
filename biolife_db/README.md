# BioLife Water — база контекста для AI-генератора рекламы

База отвечает на вопрос: **«какой рекламный ролик делать в этот день?»** — по дате, погоде и блюду возвращает готовый бриф (психологический фреймворк, тон, визуал, блюда, SKU, запреты).

## Файлы
| Файл | Что это |
|---|---|
| `seed_data.json` | **Главный источник данных.** Правите только его |
| `build_seed_sql.py` | Превращает JSON в `03_seed.sql` и проверяет все ссылки |
| `01_schema.sql` | Таблицы, типы, связи (PostgreSQL 14+, схема `biolife`) |
| `02_functions.sql` | Функция `resolve_ad_context()` — «мозг» (Раздел 3) |
| `03_seed.sql` | Сгенерированные INSERT'ы (руками не править) |
| `04_tests.sql` | 23 автотеста |
| `runtime_contract.schema.json` | Формат входа/выхода для генератора |
| `examples/*.json` | Реальные ответы базы: Чилля +43°C, Рамадан, Навруз, свадьба |

## Запуск (Supabase / любой PostgreSQL)
```bash
python3 build_seed_sql.py              # после любой правки seed_data.json
psql "$DB_URL" -f 01_schema.sql -f 02_functions.sql -f 03_seed.sql
psql "$DB_URL" -f 04_tests.sql         # все строки должны быть PASS
```
В Supabase SQL Editor: вставить файлы 01 → 02 → 03 по очереди.

## Вызов из генератора
```sql
SELECT biolife.resolve_ad_context(
  p_date => '2027-07-15', p_temp_c => 43, p_dish_key => 'osh', p_trend => NULL);
```
Все параметры необязательны. Результат — JSON-бриф, который целиком подаётся в промпт LLM.

## Логика выбора (запасные варианты)
1. **Событие дня** (самый высокий `priority`) → его фреймворк с наибольшим весом.
2. Нет события → фреймворк **месяца** из `annual_calendar_grid`.
3. Нет месяца → **глобальный дефолт** (`HYBRID_SPRING_RENEWAL`).
4. Поверх — **правила** `inference_rules`: жара ≥35°C → PEPSI + 0.5L; холод ≤5°C → без льда; тренд → хук в первые 2 сек; **Рамадан/Хайиты/9 мая всегда перекрывают жару** (эмоциональный, уважительный тон).

Поле `fallback_level` в ответе показывает, какой уровень сработал.

## Ежегодное обслуживание (обязательно)
Даты Рамадана и Хайитов плавающие. В `event_occurrences` внесены **оценки на 2026–2028** (`is_confirmed: false`). Каждый год после объявления Духовного управления мусульман Узбекистана (muslim.uz) обновите даты и поставьте `is_confirmed: true`. Пока стоит `false`, бриф выдаёт предупреждение.

## Как расширять
- Новое событие: добавить объект в `cultural_events_seasons` + хотя бы 1 запись в `event_framework_mappings` (скрипт не даст забыть).
- Новый фреймворк: `ALTER TYPE biolife.framework_type ADD VALUE 'NEW_NAME';` + строка в JSON.
- Новое правило: объект в `inference_rules`. Условия: `temp_gte`, `temp_lte`, `month_in`, `event_key_in`, `trend_present`. Действия: `framework`, `sku`, `tone_modifier`, `visual_modifier`, `note`.
